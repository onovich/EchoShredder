# EchoShredder

一个可直接部署到 GitHub Pages 的纯静态网页项目。

## 特性

- 无需构建工具，直接打开 `index.html` 即可运行
- 保留赛博碎纸机交互和回响反馈
- 不依赖后端，不在前端暴露任何 API 密钥

## 本地预览

直接在浏览器中打开 `index.html`，或使用任意静态服务器预览。

## GitHub Pages

将仓库推送到 GitHub 后，可在仓库的 Pages 设置中选择：

- Branch: `main`
- Folder: `/ (root)`

随后可通过：

- `https://onovich.github.io/EchoShredder/`

访问页面。
